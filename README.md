# Gabrielly Opuszka — protótipo do app cliente

Protótipo responsivo de agendamento para um estúdio de beleza, feito com HTML, CSS e JavaScript sem dependências de build.

## Executar

Abra `index.html` no navegador ou use a extensão Live Server do VS Code nesta pasta.

## O que está demonstrado

- Navegação responsiva e catálogo de serviços com duração e preço ilustrativos.
- Identidade visual Studio urbano, com rosa bebê e cinza como cores principais.
- Fluxo de pré-agendamento com serviço, data, horário e resumo.
- Área de conta com telas de entrada e cadastro apenas visuais.
- Atualização do próximo horário na página após confirmar o pré-agendamento.

Os dados são exemplos e ficam apenas na página atual. Autenticação, armazenamento, disponibilidade real, painel administrativo e integração com WhatsApp exigem um servidor e serviços conectados; não estão implementados neste protótipo.

# Studio Gabrielly Opuszka

Front-end responsivo em HTML, CSS e JavaScript, sem dependências ou etapa de instalação. Para visualizar, abra `index.html` no navegador ou no VS Code com uma extensão de servidor local.

## Arquivos

- `index.html`: perfil do estúdio, contatos, redes sociais, categorias e janelas de agendamento.
- `styles.css`: identidade visual jovem em rosa pastel e lilás, com ajustes para telas menores.
- `script.js`: catálogo de serviços, filtros por categoria e solicitações de agendamento salvas no navegador.

## Personalização

Atualize o endereço, telefone, links do Instagram e WhatsApp e texto de apresentação em `index.html`. Ajuste os nomes, descrições e valores dos serviços no início de `script.js`. O campo `price` aceita um número (por exemplo, `price: 120`) e será exibido em reais; enquanto estiver como `null`, o cartão mostra “A confirmar”. Para exibir fotos dos cílios, preencha o campo `image` de cada serviço com o caminho da imagem, por exemplo `image: "images/fio-a-fio.jpg"`, e coloque a foto nessa pasta. Enquanto o campo estiver vazio, o cartão mostra um espaço reservado para a foto. As imagens de capa e perfil também podem ser trocadas em `index.html` e `styles.css`.

Os agendamentos são apenas uma demonstração local: ficam salvos no navegador utilizado e não são enviados ao estúdio. A lista de serviços, endereço, telefone e links devem ser confirmados antes da publicação.
